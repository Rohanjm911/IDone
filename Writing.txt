IDone — Decentralized Identity Vault

Build a complete, production-quality web application called IDone.

1. PROJECT OVERVIEW

IDone is a privacy-focused Decentralized Identity Vault that allows users to:

- Create and manage a decentralized identity
- Store digital credentials securely
- Manage Verifiable Credentials
- Encrypt sensitive vault data
- Verify credentials cryptographically
- Share credentials selectively
- Track credential activity
- Use blockchain for identity/credential proofs and status
- Maintain user ownership and control of identity data

Core philosophy:
«Your Identity. Your Credentials. Your Control.»

Do NOT build this as a generic blockchain dashboard.

The application should feel like a combination of:

- Premium digital wallet
- Modern banking application
- Professional cybersecurity product

It must feel trustworthy, calm, minimal, and polished.

---

2. IMPORTANT DEVELOPMENT RULES

- Do NOT use Docker.
- Do NOT create unnecessary folders.
- Do NOT over-engineer the architecture.
- Do NOT create placeholder-only pages.
- Do NOT generate fake functionality where a working implementation is possible.
- Keep the code modular but simple.
- Use TypeScript strictly on the frontend.
- Use Python/FastAPI on the backend.
- Keep sensitive data encrypted.
- Never store raw sensitive identity documents directly on-chain.
- Never expose private keys or secrets to the frontend/backend logs.
- Use environment variables for secrets.
- Add proper error handling and validation.
- Build responsive desktop and mobile interfaces.
- Use accessible semantic HTML.
- Use loading, empty, success, warning, and error states.
